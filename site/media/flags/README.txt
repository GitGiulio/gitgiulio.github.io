The room's pool contains the 193 UN member states plus the Holy See (Vatican City) and Palestine, using ISO alpha-2 codes. Territories and other non-member states are excluded.
Membership reference: https://www.un.org/en/about-us/member-states
Observer reference: https://www.un.org/en/about-us/non-member-states

Only these SVG assets are bundled. No flag-icons JavaScript, CSS or npm dependency is installed.
